# Statistical-Analysis-of-Epidemic-Diseases-in-South-India-2017-2023-
The project studies disease cases and fatalities across Tamil Nadu, Kerala, Karnataka, Telangana and Andhra Pradesh.

## 1. Project Overview
This project presents a statistical analysis of epidemic diseases across five South Indian states: Tamil Nadu, Kerala, Karnataka, Telangana, and Andhra Pradesh, covering the period 2017–2023.

The study analyzes affected cases and fatalities to understand disease patterns and regional variations.

## 2. Objectives
- Identify epidemic diseases across South Indian states.
- Analyze disease cases state-wise and year-wise.
- Examine fatalities caused by different diseases.
- Compare epidemiological patterns across states.
- Identify the states and diseases with higher reported cases.

## 3. Study Area
- Tamil Nadu
- Kerala
- Karnataka
- Telangana
- Andhra Pradesh

## 4. Dataset
The project uses an Excel dataset containing information about affected cases and deaths.

File: `PROJ_DATA.xlsx`

## 5. Tools Used
- IBM SPSS
- Microsoft Excel

## 6. Statistical Techniques
- Frequency Distribution
- Descriptive Statistics
- Bar Chart Representation
- Chi-Square Test
- One-Way ANOVA

## 7. Project Report
The complete project documentation is available in `Project_Report/Group_9_Final_Report.pdf`.

## 8. Conclusion
This study provides a statistical comparison of epidemic diseases across five South Indian states during 2017–2023. It uses statistical techniques and graphical representations to examine disease occurrence, affected cases, and fatalities.
